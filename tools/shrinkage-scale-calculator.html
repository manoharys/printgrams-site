How it's calculated

compensation scale % = 100 / (1 − shrinkage % / 100)
fit scale %          = current scale × target size / measured size
  • Scaling by “+0.8%” is not quite right for 0.8% shrinkage — you need 100 / 0.992 = 100.806%. The difference matters for press fits.
  • Shrinkage depends on part geometry and cooling, so the measured method (print, measure, correct) beats the material table.
  • Holes shrink more than outer dimensions because the perimeter pulls inward. Add 0.15–0.3 mm to small holes or use your slicer's hole compensation.

Questions people ask

How much does ABS shrink when 3D printed?

Typically 0.5–1.0% linear. ASA is similar (0.4–0.7%), PETG 0.2–0.8%, PLA only 0.2–0.3%, nylon 1–2%, polypropylene 1–3%.

Should I scale in X, Y and Z equally?

Usually X and Y only. Z shrinkage is partly absorbed layer by layer as each new layer is deposited at the right height.
