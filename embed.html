How to add it

  1. Choose a default currency and, optionally, your usual filament price per kg.
  2. Click Copy code.
  3. Paste it into an HTML block or custom-HTML widget on your page and publish.

You can also use the full 3D print cost calculator with printer wear, labour and markup.

Can't use iframes? Link to it instead

Some sites don't allow embedded frames. You can add a plain link instead, which works anywhere HTML is allowed:

<a href="https://printgrams.com/tools/3d-print-cost-calculator">Free 3D print cost calculator (PrintGrams)</a>

You can also copy our data tables as they are, for example empty spool weights or hotend flow rates, with a link back as the source.

Questions about the widget

Is the widget really free?

Yes. There is no sign-up, no API key and no cost. The calculator runs entirely in the visitor's browser and credits PrintGrams with a small link at the bottom.

Does it work on WordPress, Blogger, Shopify and Webflow?

Any platform that lets you paste custom HTML (an HTML block, widget or embed element) works, because the widget is a plain iframe.

Can I set default values?

Yes. Add URL parameters to the iframe address: grams, price (per kg), hours, watts, rate (per kWh) and cur (currency code). Example: /embed/cost?cur=EUR&price=24&rate=0.30.

Does it support dark mode?

The widget follows the visitor's light or dark colour scheme automatically.
